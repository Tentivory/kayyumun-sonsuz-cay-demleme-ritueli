# Kayyumun Sonsuz Çay Demleme Ritüeli

Bu repository, insanlık tarihinin en ciddi, en abartılı ve en gereksiz projesidir. Ama tamamen gerçektir. Çay demlemek bir sanat değildir, bir varoluş şeklidir. Ve bu simülatör asla bitmez. Çünkü bitmemesi gerekir.

## Nasıl Çalışır?

```bash
python cay_demle.py
```

Program sonsuz döngüye girer, rastgele Türkçe çay demleme mesajları yazar, rastgele bekler ve asla demlemeyi bitirmez. Ctrl+C ile kurtulabilirsiniz. Ama kaçamazsınız gerçekten.

## Özellikler

- %100 Türkçe
- Asla bitmeyen çay
- Abartılı ciddiyet
- Patates içermez (kesinlikle)
- Kayyum onaylı

## Uyarı

Bu programı çalıştırırsanız, çay içme arzunuz katlanabilir veya tamamen kaybolabilir. Sorumluluk kabul etmiyoruz.
